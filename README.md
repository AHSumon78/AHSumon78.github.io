# Abul Hasan Sumon — Portfolio

Personal portfolio for **AHSumon78**, prepared for https://ahsumon78.github.io/.

Responsive static HTML, CSS and JavaScript. Includes project filters, accessible mobile navigation, social metadata and redirects for the former About and Contact pages.

## Local preview

Run `python -m http.server 8080` from this directory, then visit http://localhost:8080.

## Edit

- Content, email, social links and projects: `index.html`
- Colors, typography and responsive layout: `styles.css`
- Navigation and filters: `script.js`
- Portrait: `assets/portrait.jpg` (original supplied photograph, framed with CSS)

The project artwork is illustrative CSS, not application screenshots. Fonts use Google Fonts with local fallbacks. No build tools or API keys are required.

## Publish

Push to this repository's `main` branch. In GitHub Settings → Pages, choose **Deploy from a branch**, **main**, **/ (root)**.

Content was based on the owner's previous website and public repositories. Education and employment are omitted until confirmed. Section structure and cyan accents were inspired by https://nazmulhasan77.github.io/; implementation and layout are original.
